Use this when the execution is stuck, for example on a worker command that never returns.{{if $t}} Task {{$t.Key}} {{$t.Name}} restarts from the beginning.{{end}}

! Interrupts running work Clearing processes abandons the worker command in flight (it is cancelled and never resent), kills a running validation command, cancels a running task analysis or fix, and withdraws a requested pause after the task. The task is then requeued: the worker context is cleared (a new session; the previous one is deleted at the provider), the task is reset with its manual approvals withdrawn and its fix and retry counters reset, and the workflow returns to acceptance, where the overseer loads it again. Code changes already made in the repository are kept.
